DEPLOYMENT (Namecheap / any host)
  1. Log in to your hosting control panel (cPanel) -> File Manager.
  2. Open the "public_html" folder (your live web root).
  3. Upload all four .html files into public_html.
  4. Done — your site is live. index.html loads automatically.
  (Each page is self-contained: images, fonts, styles, scripts, and the
   favicon are all embedded, so there are no extra folders or broken links.)
