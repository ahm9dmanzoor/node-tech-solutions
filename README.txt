DEPLOYMENT (Namecheap / any host)
  1. Log in to your hosting control panel (cPanel) -> File Manager.
  2. Open the "public_html" folder (this is your live web root).
  3. Upload all four .html files into public_html.
  4. Done — your site is live at your domain. index.html loads automatically.

  (Each page is fully self-contained: images, fonts, styles, and scripts
   are embedded, so there are no extra folders or broken links to worry about.)
